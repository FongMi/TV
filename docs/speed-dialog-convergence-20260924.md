# 倍速面板整理 — 2026-09-24

手機與 Leanback 改為同一組八個可見預設速度；數值仍取自既有 `SpeedSetting.getPresets()`，沒有更動速度設定或儲存規則。預設 chip 用 Flexbox 等寬換行，移除原本永遠隱藏的第 9–12 個 view。Leanback 長按倍速滑桿的向下焦點改指向目前速度最接近的預設 chip。

「跳過靜音」整列不再代按開關，只有 switch 本身可點擊；這是使用者指定的互動範圍，不是等價重構。重設按鈕向下仍導向速度滑桿。手機和 Leanback Java 編譯通過後仍需實際檢查八個 chip 換行、開關點擊及遙控器上下左右焦點。
